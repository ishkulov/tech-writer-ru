# tech-writer-ru

Навык помогает писать, редактировать и проверять техническую документацию на русском языке в IT. Он также переводит тексты с других языков. Навык опирается на принципы ASD-STE100, ГОСТ Р 58049-2017 (раздел 8.2) и ISO 24495-1.

## Overview

tech-writer-ru is an Agent Skill for writing, editing, and reviewing technical documentation in Russian. It translates technical texts into Russian as well.

The skill turns eight rules of simplified technical Russian into a repeatable workflow. The rules adapt the principles of ASD-STE100, GOST R 58049-2017 (section 8.2), and ISO 24495-1.

Install with one command: `npx skills add ishkulov/tech-writer-ru`.

Use the skill for procedures, README files, UI text, and error messages. It works in any agent that supports the Agent Skills specification: Claude Code, Codex, Cursor, GitHub Copilot, Gemini CLI, OpenCode, and others.

## Что делает навык

- **Пишет и редактирует.** Создаёт новый текст или правит существующий. Переводит тексты с других языков на русский.
- **Проверяет.** Находит нарушения правил. По каждому даёт фрагмент, правило и исправление.
- **Работает с разными документами.** Инструкции, README, тексты интерфейса, сообщения об ошибках.

## Восемь правил

1. **Одно понятие — один термин.** Используйте выбранный термин во всём тексте. Метки интерфейса копируйте из продукта.
2. **Активный залог.** Пишите, кто и что делает. Пассив — только если исполнитель неизвестен.
3. **Простые слова.** Заменяйте канцелярские слова простым глаголом. Убирайте жаргон.
4. **Короткие предложения.** Одно действие — одно предложение. Не больше 20 слов.
5. **Короткие абзацы и цепочки.** Один абзац — одна тема, не больше 6 предложений. В цепочке существительных не больше трёх слов.
6. **Проверяемый шаг.** Начинайте шаг с глагола-команды: «Нажмите», не «Нажми». Шаг — одно действие и видимый результат.
7. **Предупреждение перед риском.** Сразу после сигнального слова пишите риск и действие. Сигнальные слова: **ОПАСНО**, **ВНИМАНИЕ**, **ОСТОРОЖНО**.
8. **Названия, латиница, единицы.** Названия продуктов пишите латиницей: GitHub, Docker. Единицы измерения указывайте в метрической системе.

Полные формулировки и критерии готовности — в `SKILL.md`. Источник истины — `SKILL.md`, а не эта страница. Дополнительные примеры — в `references/examples.md`.

## Примеры «было → стало»

| Плохо | Хорошо | Правило |
| --- | --- | --- |
| Файл был сохранён пользователем. | Пользователь сохранил файл. | Активный залог |
| Выполните настройку подключения к базе данных. | Настройте подключение к базе данных. | Простые слова |
| Пофиксили баг с логином, юзеры довольны. | Исправили ошибку входа, пользователи довольны. | Термины и простые слова |

## Установка

Для установки нужен Node.js 22.20 или новее.

В текущий проект:

```bash
npx skills add ishkulov/tech-writer-ru
```

Глобально, для всех проектов:

```bash
npx skills add ishkulov/tech-writer-ru -g
```

Обновить навык:

```bash
npx skills update tech-writer-ru
```

Удалить навык:

```bash
npx skills remove tech-writer-ru
```

## Использование

Агент вызывает навык автоматически, если задача совпадает с описанием из `SKILL.md`. Вызовите навык вручную способом, который принят в вашем агенте: упоминанием, слэш-командой или просьбой.

```text
@tech-writer-ru отредактируй этот текст
```

```text
Примени навык tech-writer-ru и отредактируй этот текст.
```

В OpenCode упомяните навык в запросе:

```text
@tech-writer-ru проверь этот текст
```

```text
@tech-writer-ru переведи этот текст с английского на русский
```

## Настройка

**ВНИМАНИЕ:** `npx skills update` может заменить файлы установленного навыка. Храните изменения в отдельной копии репозитория.

1. Склонируйте репозиторий или сделайте форк.
2. Замените примеры в `references/examples.md` на примеры из вашего продукта.
3. Добавьте термины продукта в таблицу запрещённых слов в `references/examples.md`.
4. Установите навык из локального каталога:

   ```bash
   npx skills add ./tech-writer-ru
   ```

   Замените `./tech-writer-ru` на путь к вашей копии.
