# Чек-лист

Пройдите все пункты. Если пункт неприменим к режиму или жанру, убедитесь, что это так.

## 1. Задача, жанр и факты

- [ ] Режим выбран, задача читателя сформулирована.
- [ ] Жанр определён; структура соответствует `genres.md`.
- [ ] Регистр определён: пользовательская документация, внутренняя документация или внутренняя переписка.
- [ ] У каждого факта есть источник или пометка «недостаёт»; непроверяемые факты не выданы за проверенные.
- [ ] Плейсхолдеры `{...}` перечислены.

## 2. Термины и разметка

- [ ] Одно понятие — один термин; отклонения объяснены.
- [ ] Термин взят из глоссария; запрещённые синонимы не использованы.
- [ ] Пройдена быстрая проверка по `lint.md`.
- [ ] Разные понятия не смешаны: авторизация и аутентификация, пароль и токен, ошибка и сбой.
- [ ] Метки интерфейса и код совпадают с источником.
- [ ] UI-метки — жирным, код — моноширинным.
- [ ] Аббревиатуры расшифрованы или входят в исключения.
- [ ] Названия продуктов не транслитерированы; род и краткие формы — по глоссарию.
- [ ] «Ключ API» или «API-ключ» — по глоссарию или интерфейсу.

## 3. Локализация

- [ ] Род, число и падежи проверены по `localization.md`.
- [ ] Плюрализация верна: 1 файл, 2 файла, 5 файлов.
- [ ] Плейсхолдеры не изменены.
- [ ] Форматы дат, чисел, валют и единиц едины.
- [ ] UI-строки помещаются; нет обрезанных слов.
- [ ] Нет транслитерации названий продуктов.

## 4. Шаги и структура

- [ ] Каждый шаг начинается с глагола и показывает результат.
- [ ] Условие стоит перед действием; предпосылки не пропущены.
- [ ] В инструкциях — повелительное наклонение; «пользователь» не заменяет «вы» без причины.
- [ ] Для инструкций, UI-текстов, ошибок, примечаний к выпуску, API/CLI и README применена структура из `genres.md`.

## 5. Риски и данные

- [ ] Каждое предупреждение стоит перед риском; для каждой опасной команды указан откат или необратимость.
- [ ] В примерах нет реальных секретов, токенов, паролей и персональных данных.

## 6. Доступность

- [ ] Ссылки описательные, понятны без контекста.
- [ ] У изображений есть альтернативный текст.
- [ ] Нет инструкций, которые зависят только от цвета.
- [ ] Нет стереотипных и эйблистских формулировок.

## 7. Режим и выдача

- [ ] Формат источника сохранён; в тексте нет противоречий и повторов.
- [ ] Недостающие факты и допущения перечислены.
- [ ] Критерий режима из `SKILL.md` выполнен.
- [ ] Формат режима соблюдён: ревью — два блока таблиц, редактура — объяснения изменений, перевод — решения по терминам, черновик — «Что уточнить».
