# Терминология

Глоссарий продукта важнее этого файла. Один термин — одно понятие. Если глоссарий и интерфейс расходятся, используйте термин глоссария в тексте. Метку интерфейса приводите точно в шагах.

## Спорные пары

| Понятие | Использовать | Комментарий |
| --- | --- | --- |
| Пользователь, клиент, юзер | пользователь | «Клиент» — отдельная роль. «Юзер» — только во внутренней переписке. |
| Логин, имя пользователя | по метке интерфейса | Если интерфейс говорит «Логин», используйте «логин». Иначе — «имя пользователя». |
| Авторизация, аутентификация | различайте | Аутентификация проверяет личность. Авторизация проверяет права. |
| Пароль, токен, ключ доступа | различайте | Это разные учётные данные. |
| Удалить, очистить | различайте | «Удалить» — объект. «Очистить» — содержимое. |
| Нажать, кликнуть | нажать | Кнопка — «нажать». Пункт меню — «выбрать». |
| Ошибка, сбой, дефект | различайте | «Ошибка» — для пользователя. «Сбой» — отказ сервиса. «Дефект» — ошибка в продукте. |
| Функция, возможность, фича | функция | «Возможность» — только в оборотах вроде «возможность экспорта». «Фича» — только для внутренней документации. |
| Репозиторий, репа, хранилище | репозиторий | «Хранилище» — только для хранения данных. |
| Развёртывание, деплой | развёртывание | «Деплой» — только для внутренней документации. |
| Конфигурация, конфиг | конфигурация | «Конфиг» — только для внутренней документации. |
| Обновление, апдейт | обновление | «Апдейт» — только для внутренней документации. |
| Каталог, папка | по метке интерфейса | Если интерфейс говорит «Папка», используйте «папка». Иначе — «каталог». |
| Интерфейс, UI | интерфейс | «UI» — в составных терминах: UI-текст, UI-тест. |

## Продукты, код и лексика

- Пишите названия продуктов точно: GitHub, Docker, Kubernetes, PostgreSQL. Не переводите и не склоняйте.
- Сохраняйте регистр кода: `user_id`, `Content-Type`, `GET`. Не переводите имена параметров и методов.
- Расшифровывайте аббревиатуру при первом упоминании. API, SDK, CLI, UI и URL не расшифровывайте.
- Латинские аббревиатуры не склоняйте: «в API», «с SDK». Пишите «API-ключ», «UI-тест».
- Заменяйте необоснованные англицизмы и кальки. Примеры — в `style.md`.

## Настройка под продукт

- Замените таблицу на глоссарий продукта.
- Добавьте термины из интерфейса.
- Укажите запрещённые синонимы.
- Проверьте, что правила согласуются с API.
