# Примеры

Дополнительные примеры к правилам `SKILL.md`. Одна пара к каждому правилу есть в самом `SKILL.md`.

## 1. Термины

Плохо: Удалите крышку. … Установите кожух.
Хорошо: Удалите крышку. … Установите крышку.

## 2. Залог и наклонение

Плохо: Сессии удаляются системой автоматически.
Хорошо: Система удаляет сессии автоматически.

Допустимо: Сессии удаляются автоматически через 30 дней.

## 3. Простые слова

Плохо: Пофиксили баг с логином.
Хорошо: Исправили ошибку входа.

Плохо: Юзер кликнул по кнопке и получил ошибку.
Хорошо: Пользователь нажал **Сохранить**. Появилась ошибка.

## 4. Короткие предложения

Плохо: Чтобы изменить параметры подключения к базе данных, откройте раздел настроек, найдите блок «База данных», измените значения и сохраните изменения.
Хорошо: 1. Откройте раздел настроек. 2. Найдите блок «База данных». 3. Измените значения. 4. Нажмите **Сохранить**.

## 5. Цепочки

Плохо: Настройте сеть, доступ и т. д.
Хорошо: Настройте сеть и доступ.

## 6. Шаг

Плохо: Подключите интеграцию.
Хорошо: 1. Откройте раздел **Настройки**. 2. Выберите **Интеграции**. 3. Нажмите **Подключить**. Появится окно авторизации.

## 7. Предупреждения

**ОПАСНО:** Перед снятием крышки сервера отключите питание. Внутри есть опасное напряжение.

**ВНИМАНИЕ:** Команда `rm -rf` удаляет файлы без возможности восстановления. Проверьте путь перед запуском.

**ОСТОРОЖНО:** Смена тарифа может увеличить стоимость. Проверьте условия перед подтверждением.

## 8. Латиница

Плохо: В Докере не хватает памяти.
Хорошо: В Docker не хватает памяти.

## Запрещённые слова

| --- | --- | --- |
| юзер | пользователь | внутренняя переписка |
| кликнуть | нажать | внутренняя переписка |
| репа | репозиторий | внутренняя документация |
| деплой | развёртывание | внутренняя документация, метка интерфейса |
| конфиг | конфигурация | внутренняя документация, метка интерфейса |
| апдейт | обновление | внутренняя документация, метка интерфейса |
| фича | функция, возможность | внутренняя документация |
| баг | дефект, ошибка | внутренняя документация |
| из коробки | без дополнительной настройки | — |
| бесшовный | без дополнительных действий | — |
| робастный | надёжный, устойчивый | — |
| юзать | использовать | — |
| чекать | проверять | — |
| дружелюбный к пользователю | удобный | — |
