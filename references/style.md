# Примеры стиля

Примеры к правилам конституции. Правила — в `SKILL.md`.

## 1. Термины и лексика

**Один термин — одно понятие.**

Плохо: Пользователь открывает проект. Пользователь выбирает настройки. Юзер запускает сборку.
Хорошо: Пользователь открывает проект. Пользователь выбирает настройки. Пользователь запускает сборку.

**Канцеляризмы.**

| Канцеляризм | Замена |
| --- | --- |
| осуществить настройку | настроить |
| произвести проверку | проверить |
| выполнить установку | установить |
| является | это, —, глагол по смыслу |
| данный | этот |
| в целях | чтобы |
| посредством | с помощью |
| в настоящее время | сейчас |

Плохо: Для осуществления настройки подключения необходимо выполнить редактирование файла конфигурации.
Хорошо: Чтобы настроить подключение, отредактируйте файл конфигурации.

**Кальки и сленг.**

| Плохо | Хорошо |
| --- | --- |
| сделать уверенным | убедиться |
| из коробки | без дополнительной настройки |
| бесшовный | без дополнительных действий |
| робастный | надёжный, устойчивый |
| юзать | использовать |
| чекать | проверять |
| дружелюбный к пользователю | удобный |

Для внутренней документации допустимы разговорные термины, если команда так говорит. Список — в `terminology.md`.

**Тон.**

Плохо (обвинение): Вы ввели неверный пароль.
Хорошо: Пароль не подошёл.

Плохо: Мы сохранили файл.
Хорошо: Система сохранила файл.

Убирайте «просто», «легко», «очевидно», «всего лишь».

## 2. Глаголы и залог

**Активный залог.**

Плохо: Файл был загружен пользователем.
Хорошо: Пользователь загрузил файл.

Допустимо: Сессии удаляются автоматически через 30 дней.

**Повелительное наклонение.**

Плохо: Открыть меню. Нажать **Сохранить**.
Хорошо: Откройте меню. Нажмите **Сохранить**.

**Отглагольные существительные.**

Плохо: Произведите удаление временных файлов.
Хорошо: Удалите временные файлы.

**Деепричастные обороты.**

Плохо: Открыв раздел **Настройки**, выберите **Профиль**.
Хорошо: 1. Откройте раздел **Настройки**. 2. Выберите **Профиль**.

**Цепочки родительного падежа.**

Плохо: Инструкция по настройке процесса развёртывания приложения.
Хорошо: Как настроить развёртывание приложения.

**Подлежащее и сказуемое.**

Плохо: При ошибке — перезапуск.
Хорошо: Если появится ошибка, перезапустите службу.

## 3. Синтаксис

**Одно действие — одно предложение.**

Плохо: Введите имя, пароль и нажмите **Войти**.
Хорошо: 1. Введите имя пользователя. 2. Введите пароль. 3. Нажмите **Войти**.

**Длина предложений.**

Плохо: Чтобы изменить параметры подключения к базе данных, откройте раздел настроек, найдите блок «База данных», измените значения и сохраните изменения.
Хорошо: 1. Откройте раздел настроек. 2. Найдите блок «База данных». 3. Измените значения. 4. Нажмите **Сохранить**.

**Условия.**

Плохо: Нажмите **Удалить**, если проект больше не нужен.
Хорошо: Если проект больше не нужен, нажмите **Удалить**.

**Списки.**

Плохо: Настройте сеть, доступ и т. д.
Хорошо: Настройте сеть и доступ.

## 4. Оформление

**Метки интерфейса.**

Плохо: Нажмите на кнопку «Сохранить».
Хорошо: Нажмите **Сохранить**.

Плохо: Нажмите на **кнопку Сохранить**.
Хорошо: Нажмите **Сохранить**.

**Клавиши.**

`Ctrl+S`, `Cmd+S`, `Alt+F4`.

**Код и значения.**

`user_id`, `Content-Type`, `GET`, `<token>`.

**Ссылки.**

Плохо: Подробнее здесь.
Хорошо: Подробнее в [инструкции по миграции](https://example.com).

**Типографика.**

- «» — цитаты и названия; “” — вложенные.
- Длинное тире — с пробелами; среднее — в диапазонах: 10–20.
- Дефис — в составных словах: API-ключ, UI-тест.
- «19 ноября 2026» или «19.11.2026» — один формат.
- «2,5 секунды» в тексте; «2.5» в коде.

## 5. Предупреждения

**ОПАСНО:** Перед снятием крышки сервера отключите питание. Внутри есть опасное напряжение.

**ВНИМАНИЕ:** Команда `rm -rf` удаляет файлы без возможности восстановления. Проверьте путь перед запуском.

**ОСТОРОЖНО:** Смена тарифа может увеличить стоимость. Проверьте условия перед подтверждением.

Сигнальные слова — только для рисков.

## 6. Редактура

Исходный текст: Производится настройка подключения к базе данных.
Правка: Настройте подключение к базе данных.
Причина: отглагольное существительное и пассив.
